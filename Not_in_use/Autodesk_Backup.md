### Introduction

Autodesk is a leading force in the design and BIM industries, widely recognised for its extensive range of software solutions and large global user base. In OENG1191, we will be utilising the following Autodesk software:

|                                      | Name                                       | Description                                                                                                                                                                                                            |
| :----------------------------------: | :----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![[Pasted image 20250131152235.png]] | **Revit**                                  | Revit is a powerful BIM software that enables architects, engineers, and designers to create, coordinate, and manage building information models with precision and efficiency.                                        |
| ![[Pasted image 20250131152345.png]] | **Robot Structural Analysis Professional** | Robot Structural Analysis Professional is an advanced structural analysis software that enables engineers to simulate, analyse, and optimise complex building and infrastructure designs with precision and efficiency |
| ![[Pasted image 20250131152355.png]] | **Navisworks Manage**                      | Navisworks Manage is a comprehensive project review software that enables teams to integrate, visualize, and coordinate multidisciplinary models, detect clashes, and improve construction planning and collaboration  |
### Create account with education access

| Steps | To do                                                                                                                                                                                      |
| :---: | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | Go to this Autodesk education access [website](https://www.autodesk.com/education/edu-software/overview?sorting=featured&filters=individual). (Right-click and open the link in a new tab) |
| **2** | Click ==Sign in== on top right of the page.                                                                                                                                                |
|       | ![[Pasted image 20250123152519.png]]                                                                                                                                                       |
| **3** | In the following ==Sign in== page, click ==Create account==.                                                                                                                               |
|       | ![[Pasted image 20250123152557.png]]                                                                                                                                                       |
| **4** | Use your ==RMIT student email== to create account.                                                                                                                                         |
| **5** | Now you can proceed to get access to specific software.                                                                                                                                    |

> [!info] For students who have previously applied for an Autodesk education account:
> An Autodesk education account is valid for only one year and requires annual renewal. The expiration date of software products under the education account aligns with the account itself. If you have previously applied for an Autodesk education account, please refer to Steps 10 - 12 to check the account's expiration date and renew it accordingly.

### Download software

| Steps  | To do                                                                                                                                                                                                                                                         |
| :----: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **13** | ==Logging in== to the Autodesk education [website](https://www.autodesk.com/education/edu-software/overview?sorting=featured&filters=individual) again. (Right click and open link in new tab)                                                                |
| **14** | Click the profile logo on the top right, and click ==Products and services==.                                                                                                                                                                                 |
|        | ![[Pasted image 20250131160448.png]]                                                                                                                                                                                                                          |
| **15** | Due to issues with the Autodesk website, finding the software may be counterintuitive and misleading.                                                                                                                                                         |
| **16** | Under ==All Products and Services== page, you ==MAY NOT== find all the software you just got access to. If you do find any, click on ==Install==. This will trigger download of a tiny size installer. Make sure you are downloading the latest 2025 version. |
|        | ![[Pasted image 20250123153640.png]]                                                                                                                                                                                                                          |
| **17** | If you still have missing software, go to ==Home== tab on top left the page.                                                                                                                                                                                  |
|        | ![[Pasted image 20250131162438.png]]                                                                                                                                                                                                                          |
| **18** | Some software may appear in the ==Get Started== section on this page. If there is any, click on ==Install==. This will trigger download of a tiny size installer.                                                                                             |
|        | ![[Pasted image 20250131162631.png]]                                                                                                                                                                                                                          |
| **19** | To install each software, begin by running the installer. This installer will handle downloading and installing the software, which may take some time to complete.                                                                                           |

>[!info] Note that even if you install Revit and Navisworks on a drive other than C drive, these applications will still use a significant amount of space on the C drive. Freeing up some space on C before starting the installation process is advisable.
