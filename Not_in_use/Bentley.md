### Create and setup account 

| Steps  | To do                                                                                                                                            |
| :----: | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| **1**  | Go to this Bentley education ==[website](https://education.bentley.com/ProductLine/StructuralAnalysis)==. (Right click and open link in new tab) |
| **2**  | Click ==Log in== on top right.                                                                                                                   |
|        | ![[Pasted image 20250131112406.png]]                                                                                                             |
| **3**  | In the following page, click ==Register now==.                                                                                                   |
|        | ![[Pasted image 20250131112520.png]]                                                                                                             |
| **4**  | Create an account with RMIT student email address.                                                                                               |
|        | ![[Pasted image 20250131114140.png]]                                                                                                             |
| **5**  | Check your e-mail (check the junk mail as well) for verification code. Enter the code and click the ==Verify== button.                           |
|        | ![[Pasted image 20250131115439.png]]                                                                                                             |
| **6**  | Sign in to your account                                                                                                                          |
|        | ![[Pasted image 20250131115302.png]]                                                                                                             |
| **7**  | You’ll see this pop-up window. Click ==SETUP== to update your profile                                                                            |
|        | ![[Pasted image 20250131115335.png]]                                                                                                             |
| **8**  | In the following page, click ==My Profile==.                                                                                                     |
|        | ![[Pasted image 20250131115414.png]]                                                                                                             |
| **9**  | Fill the Bentley Education Profile (==Fields marked with * are mandatory==) and click the ==Save== button.                                       |
|        | ![[Pasted image 20250131115540.png]]                                                                                                             |
| **10** | Now the access to the software is granted                                                                                                        |
